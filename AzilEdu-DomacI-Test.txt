Pokretanje
----------
Terminal 1 (API):
  cd AzilEdu.Api
  dotnet user-secrets set "Ai:Provider" "Mock"    ← preporučeno za AI demo
  dotnet run --launch-profile https

Terminal 2 (App):
  cd AzilEdu.App
  dotnet run --launch-profile https

URL:
  App → https://localhost:7094
  API → https://localhost:7205/swagger

Build prije predaje:
  dotnet build AzilEdu.sln
